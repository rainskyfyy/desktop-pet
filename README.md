# 罗小黑 - 桌面宠物

一个可爱的罗小黑桌面宠物，基于 Web 技术构建的互动养成游戏。

## 功能特性

### 状态系统
- **饥饿值**：需要喂食维持
- **心情值**：影响宠物情绪
- **能量值**：进行活动需要消耗
- **健康值**：需要洗澡和看病维持
- **金币**：通过打工和学习获得
- **经验等级**：通过各种活动提升

### 工具栏
- 🍖 **喂食**：消耗10金币，增加饥饿值和心情值
- 🎾 **玩耍**：消耗15能量，大幅增加心情值和经验
- 🚿 **洗澡**：消耗15金币和10能量，增加健康值和心情值
- 💊 **看病**：消耗20金币，治疗疾病
- 📚 **学习**：消耗15能量，获得经验和金币
- 💼 **打工**：消耗30能量和25饥饿值，获得金币和少量经验

### 动画状态
- 站立待机
- 走路移动
- 跳跃
- 吃东西
- 玩耍
- 睡觉
- 撒娇（双击宠物）
- 生病

### 粒子特效
- ❤️ 爱心 - 喂食和撒娇时
- ⭐ 星星 - 玩耍和学习时
- 💰 金币 - 打工时
- 💦 水滴 - 洗澡时
- 💤 Zzz - 睡觉时
- ✨ 闪光 - 升级和治疗时
- 💧 汗滴 - 生病时

### 天气系统
- ☀️ 晴天
- 🌧️ 雨天
- ❄️ 雪天

每30秒自动切换天气

### 交互方式
- **单击宠物**：随机对话
- **双击宠物**：撒娇，增加心情值
- **点击空白处**：宠物移动到该位置
- **拖拽宠物**：可以拖动宠物到任意位置
- **触摸设备**：支持触摸操作

### 数据持久化
使用 localStorage 保存宠物状态，包括：
- 各项数值
- 等级和经验
- 金币数量
- 最后保存时间

离线时数值会自动衰减。

## 使用方法

1. 将所有文件放在同一个目录下
2. 确保 `index.html` 与罗小黑图片在同一目录
3. 用浏览器打开 `index.html` 即可

### 图片文件
需要以下5张罗小黑PNG图片：
- `luoxiaohei_stand.png` - 站立姿态
- `luoxiaohei_smile.png` - 微笑表情
- `luoxiaohei_sleep.png` - 趴着睡觉
- `luoxiaohei_jump.png` - 跳跃姿态
- `luoxiaohei_eat.png` - 吃东西

## 技术实现

- 纯原生 JavaScript 实现
- Canvas 2D 渲染
- CSS3 动画效果
- localStorage 数据持久化
- 响应式设计，支持移动端

## 兼容性

- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 支持移动端浏览器
- 支持触摸操作

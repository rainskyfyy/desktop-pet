# 罗小黑 - 桌面宠物

一个可爱的罗小黑桌面宠物，基于 Electron 构建的互动养成应用。宠物会以全屏透明窗口悬浮在桌面之上，自由走动、互动，鼠标移开时自动穿透不挡操作。

## 功能特性

### 状态系统
- **饥饿值**：需要喂食维持
- **心情值**：影响宠物情绪
- **精力值**：进行活动需要消耗，低于 15% 时自动回猫窝睡觉恢复
- **能量值**：进行活动需要消耗
- **健康值**：需要洗澡和看病维持，低于 50% 时显示生病标志
- **清洁值**：洗澡提升
- **金币**：通过打工和学习获得
- **经验等级**：通过各种活动提升

### 工具栏
- 🍖 **喂食**：消耗 10 金币，增加饥饿值和心情值
- 🎾 **玩耍**：消耗 15 能量，大幅增加心情值和经验
- 🚿 **洗澡**：消耗 15 金币和 10 能量，增加健康值和心情值
- 💊 **看病**：消耗 20 金币，治疗疾病
- 📚 **学习**：消耗 15 能量，获得经验和金币
- 💼 **打工**：消耗精力，获得金币和经验（精力消耗随等级递减）
- 😴 **睡觉**：回猫窝睡觉，精力快速回复，健康/心情小幅恢复
- 🔄 **重置**：清空存档，所有数值恢复初始状态

### 动画状态
- 站立待机（含呼吸/颤抖动画）
- 走路移动
- 跳跃
- 吃东西
- 学习
- 打工
- 睡觉（睡饱自动醒来）
- 生病（健康低于 50%）
- 死亡（健康耗尽，漂浮幽灵效果，仅可重置）

### 粒子特效
- ❤️ 爱心 - 喂食和撒娇时
- ⭐ 星星 - 玩耍和学习时
- 💰 金币 - 打工时
- 💦 水滴 - 洗澡和雨天
- ✨ 闪光 - 升级和治疗时
- 💤 Zzz - 睡觉时

### 天气系统
- ☀️ 晴天
- 🌧️ 雨天
- ❄️ 雪天

每 60 秒自动切换天气。雨雪天宠物会自动回猫窝躲雨，猫窝棚顶可遮挡粒子。

### 交互方式
- **单击宠物**：随机对话
- **双击宠物**：撒娇，增加心情值
- **点击空白处**：宠物移动到该位置
- **拖拽宠物**：可以拖动宠物到任意位置
- **触摸设备**：支持触摸操作
- **面板拖拽**：状态栏、等级、天气、工具栏均可拖动

### 桌面特性
- 全屏透明无边框窗口，始终置顶且不在任务栏显示
- 智能鼠标穿透：光标不在交互区域时点击穿透到桌面，进入交互区域自动捕获
- 系统托盘：显示/隐藏宠物、双击托盘图标切换、退出
- 单实例运行
- 主屏分辨率/缩放变化自动适配

### 数据持久化
使用 localStorage 保存宠物状态，包括各项数值、等级经验、金币、最后保存时间等。离线时数值会自动衰减。

## 环境要求

- Windows 系统
- Node.js 18+（仅开发需要）

## 安装与运行

```bash
npm install
npm start
```

## 打包成安装程序

```bash
# 使用国内镜像，避免下载 Electron 二进制卡住
npm run build:win
```

产物输出到 `dist/` 目录，生成 NSIS 安装程序。

## 项目结构

```
luoxiaohei-pet-v4/
├── index.html          # 全部游戏逻辑、渲染、UI（Canvas 2D）
├── main.js             # Electron 主进程：窗口、托盘、鼠标穿透
├── preload.js          # 预加载脚本（IPC 桥接）
├── package.json        # 依赖与打包配置
└── *.png               # 罗小黑状态素材图
```

## 技术实现

- Electron 28 桌面应用
- 原生 JavaScript + Canvas 2D 渲染
- CSS3 动画效果
- localStorage 数据持久化
- IPC 通信（`preload.js` 桥接主进程与渲染进程）
